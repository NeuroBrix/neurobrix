# Getting Started

## Prerequisites

- Python 3.10+
- One of: an NVIDIA GPU on Linux, an Apple Silicon Mac, or a CPU-only machine. The current
  release on PyPI is 0.6.16. Windows (the PyTorch engine) is on `main`, not yet in a release.
- PyTorch only if you want the PyTorch engine (see [Installation](installation.md)). The
  Triton engine needs no PyTorch.

## Steps

1. **[Install](installation.md)**: install NeuroBrix from PyPI (and PyTorch, if you want the PyTorch engine)
2. **[Quick Start](quickstart.md)**: run your first model
3. **[Model Hub](hub.md)**: browse and import models
