# Getting Started

## Prerequisites

- Python 3.10+
- PyTorch 2.1+, installed for your hardware (see [Installation](installation.md))
- An NVIDIA GPU, or a CPU-only machine. The current release (0.5.4) supports NVIDIA GPUs (CUDA)
  and CPU; Apple Silicon is not in a release yet.

## Steps

1. **[Install](installation.md)**: install PyTorch, then NeuroBrix from PyPI
2. **[Quick Start](quickstart.md)**: run your first model
3. **[Model Hub](hub.md)**: browse and import models
